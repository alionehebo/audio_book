#Sobre o Sistema
Uma aplicação web focada para leitura auditiva, onde o utilizador pode carregar um ficheiro PDF (via drag-and-drop), escolher uma voz neural de preferência e gerar áudiolivro dividido em áudio. O utilizador poderá ouvir os áudios diretamente na página ou fazer o download.


Especificações de Interface e Usabilidade (UX/UI)

Zona de Drop-zone: Um componente visual destacado no topo para arrastar o PDF.

Painel Lateral de Configurações (Sidebar): Onde o utilizador escolhe o sotaque (pt-PT ou pt-BR) e o narrador, evitando poluir o ecrã principal.

Barras de Progresso Dinâmicas: Mostrar visualmente a extração do PDF e a percentagem de conclusão da geração do áudio.
